# Triage labels

Use these five canonical triage roles and label strings:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs information | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

The label strings intentionally equal the canonical role names used by the triage skill. Do not create alternate labels for these roles in this repository.
